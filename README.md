# Sebastian Nystorm

I build tools for people who work with coding agents.

## Tools

- **[mid-flight](https://github.com/Abeansits/mid-flight)** — Ask another coding agent from inside the session you already have open.
- **[sigil](https://github.com/Abeansits/sigil)** — An agent runs only with a seal of authority. The audit log can be checked.
- **[ting](https://github.com/Abeansits/ting)** — Models propose, cross-examine, and revise. The dissent stays in the record.
- **[kunskap](https://github.com/Abeansits/kunskap)** — Sessions file what they learned. A librarian compiles a wiki.
- **[agent-radar](https://github.com/Abeansits/agent-radar)** — A menu-bar board of what your agents are doing right now.
- **[pcp](https://github.com/Abeansits/pcp)** — A menu-bar clipboard for macOS. Copy a few things, then paste them back in order.
- **[pre-flight](https://github.com/Abeansits/pre-flight)** — A hook that reviews the plan before you approve it.

## Also

- **[meeting-hype](https://github.com/Abeansits/meeting-hype)** — A Mac menu-bar app. Every video call gets a BBC-style countdown.
- **[era-chess](https://github.com/Abeansits/era-chess)** — Drag a century, then play that century's chess. [Play](https://web-production-b0fe7.up.railway.app).
- **[wobble-warz](https://github.com/Abeansits/wobble-warz)** — Plant toy soldiers. Physics decides the winner.
- **Games** — Pick a game and play in the browser. [Arcade](https://dashboard-production-0baa.up.railway.app/).
- **[Lucky Fish](https://github.com/Abeansits/lucky-fish-recreation)** — Cast, catch, collect. [Play](https://lucky-fish-production.up.railway.app/).
